# ERP Project

## Technologies Used
- **Backend:** .NET 8, Clean Architecture, CQRS, Repository Pattern, MediatR, Entity Framework Core, AutoMapper, SmartEnum, Scrutor
- **Frontend:** Angular 17, Admin LTE

## Description
A comprehensive training program on designing and developing **Enterprise Resource Planning (ERP)** systems using modern web technologies. The course focuses on building **scalable, maintainable, and high-performance applications** with **.NET 8** and **Angular 17**.

### Backend
- Implements **Clean Architecture**, **CQRS**, and **Repository Pattern** for structured development.
- Utilizes **MediatR** for in-app communication and **Entity Framework Core** for data access.
- **AutoMapper** is used for object-to-object mapping, while **Scrutor** facilitates dependency injection.
- **Result Pattern** ensures the development of robust and maintainable code.

### Frontend
- Built with **Angular 17** and styled using the **Admin LTE** theme for a modern, clean, and user-friendly interface.
- Leverages **reactive programming** principles to enhance the user experience with dynamic and interactive features.
